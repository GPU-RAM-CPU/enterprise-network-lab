Enterprise Network Lab — Cisco Packet Tracer

A simulated enterprise network connecting Headquarters (HQ) and Branch 1 (BR1), built using Cisco Packet Tracer.

Network Components##

- 3 Routers

- 3 Access Switches

- 2 Multilayer Switches

- 6 PCs

- 2 Servers

Technologies Implemented##

- OSPF: Dynamic routing between network devices

- VLANs: Network segmentation using three VLANs

- Inter-VLAN Routing: Communication between VLANs

- STP: Prevention of Layer 2 switching loops

- EtherChannel: Link aggregation between switches

- HSRP: First-hop gateway redundancy

- DHCP: Centralized IP address allocation

- DHCP Relay: Forwarding DHCP requests from the branch to the central DHCP server

- DHCP Snooping: Protection against unauthorized DHCP servers

- Port Security: Restricting access to switch ports by MAC address

Testing##

- Verified connectivity between HQ and BR1

- Tested DHCP address assignment for branch clients
  
- Tested Port Security by connecting an unauthorized device

- Successful connectivity between HQ and BR1.
